# v6 变更记录：数值规则与新增事件

## 一、数值规则（js/data.js CONFIG + js/engine.js `_choose`）

| 规则 | 实现 | 说明 |
|---|---|---|
| 四项不再保证每段全变 | 人际/声望先掷概率，未命中直接不结算 | 一段里通常只有 1-2 项真的变化 |
| 降低人际/声望变化概率 | `socialChangeChance: 0.6` | 实测 2000 次抽样 59.6% |
| 变动幅度提高 40% | `socialDeltaAmp: 1.4` | 关系 +10 的实际落点 12-14（再经收益系数 0.9） |
| 精力/心情隐藏漂移 | `driftStats: ['energy','mood']`，每段各随机 ±1 | 不写入结果卡 payload、不写入 history，只体现在侧栏 |
| 取消固定精力消耗 | 删除旧「每段 -1 精力」 | 固定消耗与漂移叠加会让低精力角色必崩 |

崩坏判定放在隐藏漂移结算之后，避免「结果卡没显示变化、实际已归零」的错位。

## 二、事件选取：进度滑窗（js/events.js `pickNext`）

事件库 76 段、单局 25 段。旧逻辑固定从可用池取前 12 个，玩家实际只能走到
order≈37，48 段之后的内容永远遇不到（v6 新增事件首次回归时实测 300 局出现 0 次）。
改为按 `turn / (turnLimit-1)` 估算学期进度、窗口起点随之向后滑，
既保留窗口内加权随机，又保证十一月、十二月章节可达。
效果：9 个新事件在 300 局随机对局中出现 83-116 次（链式后续事件 15 次）。
